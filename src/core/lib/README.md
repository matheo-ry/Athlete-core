# core/lib

Utilidades puras que usa toda la app: unidades de peso (kg/lb), fechas, logger y `cn`. Sin React y sin Supabase.

`device-drafts.ts`: el prefijo de los borradores que los módulos guardan en el dispositivo (lo que un usuario deja a medias, como una rutina) y `clearDeviceDrafts()`, que los borra todos al cerrar sesión (D-099).
